# Measurement and asset limits

The authorized Sketchfab session was unavailable in the project. Authenticated asset browsing was skipped. Two official CC0 art downloads supplied the masonry and sky. Hero assets, architecture, effects, marks and sound were built locally.

Standard headless Chromium uses SwiftShader for the fallback tests. Chromium can also access the laptop’s NVIDIA GTX 1650 with ANGLE Direct3D 11. Physical phone rendering, a physical controller and iOS Safari still require device checks. See FINAL_REPORT.md for the measured configurations.

KTX tooling was unavailable in the installed pipeline. Shipped photographic maps use WebP. WebGL texture allocation estimates reflect the tested viewport and inferred format sizes. Private reference footage has no supplied public redistribution license. Event details and the local registration flow are placeholders.
